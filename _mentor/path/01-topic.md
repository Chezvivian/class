  <h2>本阶段目标</h2>

  <h3 class="no_toc" style="font-size:15px;color:#1e40af;margin:0 0 8px;">学生要完成</h3>
  <ul class="mp-goals">
    <li>确定自己想写的翻译实践报告<strong>具体类型</strong>（教指委六大类型之一），而不是笼统地说「想写翻译实践报告」。</li>
    <li>不受培养方向（口译 / 笔译）局限——<strong>六大类型可跨方向自由选择</strong>。</li>
    <li>认真考虑后四种「新」类型：翻译项目管理、语言资产管理、项目质量审校（MTPE）、翻译技术应用。它们更贴合语言服务市场的真实岗位需求，对就业更有帮助，写作难度也不一定更高。</li>
    <li>确定类型后，进一步思考：这个类型能否贴合自己<strong>已经做过、或近期可预见会接触到</strong>的翻译实践项目，从而保证有素材可用。</li>
  </ul>

  <h3 class="no_toc" style="font-size:15px;color:#1e40af;margin:16px 0 8px;">导师关注</h3>
  <ul class="mp-goals">
    <li><strong>选题是否合理</strong>：是否出于真实的市场需求或行业现象，而不是凭空设想的问题。</li>
    <li><strong>范围是否可行</strong>：是否已收窄到可操作的程度，是否基于学生能收集到的数据、个人兴趣、合理的工作量预估。</li>
  </ul>

  <p style="margin:16px 0 0;color:#64748b;">
    翻译实践报告的本质，是从自己的翻译实践中发现问题、解决问题，为未来进入语言服务行业积累经验——这也是帮助自己从「学生思维」转换为「工作思维」的一次自我探索。把实习实践经历、所思所想所创和毕业论文写作结合起来，会是记录个人成长最好的方式。
  </p>
</div>

<div class="mp-section">
  <h2>Best Practice</h2>
  <p style="margin:0 0 12px;">
    理想的选题过程，是从「一个宽泛的实践领域」逐步收窄到「一个具体、可分析的研究问题」。以下几个方向来自往届 MTI 实践报告评阅中的真实案例（已对题目做模糊化处理，仅保留大致行业方向，供大家参考选题的收窄思路）：
  </p>
  <div class="mp-qa">
    <h4 class="no_toc">案例一 · 项目质量审校类（技术文档翻译 + 多引擎译后编辑评估）</h4>
    <p class="mp-muted">作者围绕某类技术文档的机器翻译质量，自建了多个大模型引擎的对比评测流程，并结合自动评分与人工 MQM 评分进行交叉验证，进而提出译后编辑策略建议。工作量饱满、流程完整是获得好评的关键；但也要注意：评分员分工与如何控制主观偏差要交代清楚，图表呈现（如坐标轴范围）要符合学术规范，不能通过视觉手段夸大数据差异。</p>
  </div>
  <div class="mp-qa">
    <h4 class="no_toc">案例二 · 项目质量审校类（图书节选翻译 + 译后编辑全流程）</h4>
    <p class="mp-muted">作者把「机器翻译引擎选择 → 术语抽取 → 译后编辑 → 质量评估」跑成一条完整链路，逻辑连贯，是这一类选题普遍受认可的共同点。提醒：工具、提示词、术语筛选标准等操作细节必须具体交代，不能语焉不详地一笔带过。</p>
  </div>
  <div class="mp-qa">
    <h4 class="no_toc">案例三 · 笔译实践操作类（政策文献 / 官方话语英译）</h4>
    <p class="mp-muted">选题从宽泛的「政策文本翻译」收窄为「某一理论视角下对某一类译例的系统归类与策略总结」。收窄的关键在于：先给译例分类，再针对每一类总结出具体、可操作的翻译方法，避免翻译策略「多而杂」、看不出理论对实践的具体指导作用。</p>
  </div>
  <div class="mp-qa">
    <h4 class="no_toc">案例四 · 项目质量审校类（视听字幕翻译 + 译后编辑）</h4>
    <p class="mp-muted">作者实际采用的是「机器翻译 + 译后编辑」流程，因此更准确的定位应是项目质量审校类（MTPE），而不是笼统的笔译实践类——选题类型要和实际做的工作流程对齐，题目、类型、内容三者要互相匹配。</p>
  </div>
  <p style="font-size:14px;color:#94a3b8;line-height:1.7;margin:12px 0 0;">
    一个反面提醒：研究问题不能只是「我要做的几件事」的清单（例如「我会做 MT、我会做 PE、我会做评估」），而必须是具体、可分析、可回答的问题（例如「某类文本在 MT+PE 流程中最常见的错误类型是什么，哪些译后编辑策略最有效」）。
  </p>
</div>

<div class="mp-section">
  <h2>Q&amp;A</h2>
  <div class="mp-qa">
    <h4 class="no_toc">Q1 · 我是口译方向的学生，可以写笔译类型（或反过来）的实践报告吗？</h4>
    <p class="mp-muted">可以。六大类型是按报告涉及的具体任务划分的，不是按你的培养方向划分。只要你有对应的实践素材——哪怕是短期实习、志愿服务、课程项目中积累的语料或录音——就可以跨方向选题，这在往届并不少见。</p>
  </div>
  <div class="mp-qa">
    <h4 class="no_toc">Q2 · 翻译项目管理、语言资产管理这些「新」类型，会不会比传统口笔译报告更难写？</h4>
    <p class="mp-muted">不一定。这些方向的工具链和步骤往往更清晰，只要把「做了什么、遇到了什么问题、怎么解决的」讲清楚即可，反而更容易避开「泛泛而谈」的通病；同时也更贴近当下语言服务行业的真实岗位需求，对就业有直接帮助。</p>
  </div>
  <div class="mp-qa">
    <h4 class="no_toc">Q3 · 项目质量审校类是不是只能做机器翻译译后编辑？</h4>
    <p class="mp-muted">是的。教指委原文明确标注「项目质量审校类（仅限机器翻译译后编辑）」，即该类型特指 MTPE，不包含人工译文互校、常规审校等其他质量控制形式。</p>
  </div>
  <div class="mp-qa">
    <h4 class="no_toc">Q4 · 我还没确定具体的实习/实践项目，可以先定类型吗？</h4>
    <p class="mp-muted">建议两者同步考虑。类型决定了你需要收集什么样的实践证据（原文译文、录音转写、术语表、工具操作记录等），提前想清楚类型，能让你在实习或项目进行中就有意识地记录、留存可用于后续分析的材料。</p>
  </div>
</div>

<div class="mp-section">
  <h2>自查清单</h2>
  <ul class="mp-check">
    <li>我已经明确要写六大类型中的哪一类，而不是笼统地说「想写翻译实践报告」</li>
    <li>我的选题反映了真实的市场需求或行业现象，而不是凭空设想的问题</li>
    <li>我已初步确认能获得足够的实践素材（原文/译文、录音、术语表、工具日志等），满足教指委对篇幅与附录的底线要求</li>
    <li>我认真考虑过跨方向、或后四种新类型的可能性，而不是默认选择口译或笔译实践操作类</li>
    <li>我的选题范围已经收窄到有明确、具体的问题，而不是「提升翻译质量」这类宽泛表述</li>
    <li>我已和导师初步沟通选题方向，确认了可行性</li>
  </ul>
