<div class="mp-section">
  <h2>我校要求解读（贸大英语学院 MTI）</h2>
  <p style="font-size:14px;color:#64748b;line-height:1.7;margin:0 0 12px;">
    以下把<strong>全国教指委《基本要求》（试行，2023 年 12 月编制）</strong>与<strong>英语学院《选题及写作类型指引》（2026-07-01）</strong>及学院模板对齐说明，方便开题与写作时对照。具体格式以模板与《英语学院学位论文写作规范》为准；结构若导师另有要求，以导师意见为准。
  </p>

  <h3 class="no_toc" style="font-size:15px;margin:16px 0 8px;">1. 论文类型怎么选？</h3>
  <ul class="mp-list">
    <li><strong>教指委推荐两类：</strong>案例分析报告、调研报告（其他形式由培养单位自行探索）。</li>
    <li><strong>我院对应落地：</strong>
      <ul>
        <li><strong>翻译实践报告</strong> ≈ 案例分析报告 → 用「翻译实践项目报告」开题/论文模板；</li>
        <li><strong>翻译调研报告</strong> ≈ 调研报告 → 用「翻译行业调研报告」开题/论文模板；</li>
        <li><strong>翻译研究论文</strong>仍保留在学院指引中（偏研究问题），格式参考 MA 的 APA 模板；是否选择须与导师确认，并注意与教指委「实践导向」推荐类型的关系。</li>
      </ul>
    </li>
    <li><strong>专业方向填写：</strong>模板封面为商务笔译 / 商务法律翻译 / 商务口译 / 国际会议口译（四选一）。</li>
  </ul>

  <h3 class="no_toc" style="font-size:15px;margin:16px 0 8px;">2. 语言与篇幅（务必同时满足「学院 + 附录实践量」）</h3>
  <div class="mp-table-wrap">
    <table class="mp-table">
      <thead>
        <tr>
          <th>类型</th>
          <th>学院正文要求（英文写作）</th>
          <th>实践素材 / 附录（对齐教指委）</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td>翻译实践报告（笔译）</td>
          <td>分析报告正文不少于 <strong>5,000 英语单词</strong></td>
          <td>附录提供原文与译文；原文不少于 <strong>10,000 汉字</strong>（从未有过译文的文本）</td>
        </tr>
        <tr>
          <td>翻译实践报告（口译）</td>
          <td>分析报告正文不少于 <strong>5,000 英语单词</strong></td>
          <td>附录含口译内容转写等；转写不少于 <strong>10,000 汉字/英语单词</strong>；教指委另强调音视频支撑材料时长 <strong>30 分钟以上</strong>（含原语与译语）</td>
        </tr>
        <tr>
          <td>翻译调研报告</td>
          <td>全文不少于 <strong>15,000 英语单词</strong></td>
          <td>附录提供问卷、访谈提纲/记录等支撑材料</td>
        </tr>
        <tr>
          <td>翻译研究论文</td>
          <td>不少于 <strong>15,000 英语单词</strong></td>
          <td>按研究设计提供必要附录；须与导师确认选题必要性</td>
        </tr>
      </tbody>
    </table>
  </div>
  <p style="font-size:13px;color:#64748b;line-height:1.6;">
    教指委对案例分析/调研报告正文另有「原则上不少于 10,000 汉字、原则上使用国家通用语言文字」等表述；<strong>我院 MTI 明确要求英文写作</strong>。实务上：以学院模板与英文篇幅要求完成正文，同时用附录把口/笔译实践量做足，使「问题—案例—分析」符合教指委对专业实践训练的定位。
  </p>

  <h3 class="no_toc" style="font-size:15px;margin:16px 0 8px;">3. 开题报告结构要点（来自学院模板批注）</h3>
  <div class="mp-grid-2">
    <div class="mp-card" style="cursor:default;">
      <span class="tag">实践项目报告 · 开题</span>
      <h3 class="no_toc">建议章节与篇幅</h3>
      <p>
        Ch.1 Introduction（约 800 词）：实习/项目背景 + 选题意义；<br>
        Ch.2 Literature &amp; Framework（约 1600 词）：按主题综述，忌简单「国内/国外」二分；<br>
        Ch.3 Project Implementation（约 1600 词）：研究问题、项目设计与实施步骤。<br>
        参考文献 ≥20 条，英文文献不少于 1/3；格式见学院写作规范（APA）。
      </p>
    </div>
    <div class="mp-card" style="cursor:default;">
      <span class="tag">行业调研报告 · 开题</span>
      <h3 class="no_toc">建议章节与篇幅</h3>
      <p>
        Ch.1 Introduction（约 800 字/词量级）：背景意义、行业概貌、报告结构；<br>
        Ch.2 Literature Review（约 1600 词）；<br>
        Ch.3 Project Design（对象、问题、方法、数据、分析程序）；<br>
        Ch.4 Project Implementation（重点与实施计划，约 1600）。<br>
        附录可含问卷、访谈提纲等。
      </p>
    </div>
  </div>

  <h3 class="no_toc" style="font-size:15px;margin:16px 0 8px;">4. 写给贸大学生的几条硬约束</h3>
  <ul class="mp-check">
    <li>选题须与专业方向一致；开题通过后若选题大改，需上报学院重新开题。</li>
    <li>案例须来自真实或可说明的翻译实习/实践项目；有明确问题，避免「译文赏析式」空转。</li>
    <li>笔译附录原文须「从未有过译文」；有保密协议无法附原文/录音的，需保密方签字盖章说明（教指委）。</li>
    <li>机器翻译译后编辑等可作为质量审校类选题，但须把<strong>完整专业流程与决策</strong>写清楚，而非工具说明书。</li>
    <li>开题/论文模板是格式与结构示范；引用格式以《英语学院学位论文写作规范》为准。</li>
  </ul>
</div>
